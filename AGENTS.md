# lib-tls-libssl

Nonblocking TLS primitives over libssl — step functions a scheduler
can park on. Implements the `tls` contract (`lib-tls`). Pure `.hnl`
plus codegen-generated libssl bindings under
`handl-packages/generated/` (gitignored build artifact).

## Layout

| path | role |
| --- | --- |
| `src/index.hnl` | the implementation |
| `specs/libssl.sdkgen.yaml` | committed sdkgen input |
| `handl-packages/generated/` | build artifact — regenerated by the gate, gitignored |
| `pkg.hnl` | manifest — `modules: ["tls-libssl"]`, dep `tls` |
| `scripts/hnl-gate.sh`, `workflows/gate.yaml` | the gate / bupha entry |

## Regenerate

```bash
hnl codegen c /usr/include/openssl/ssl.h \
  --output handl-packages/generated/libssl \
  --config specs/libssl.sdkgen.yaml
```

Needs libclang — set `LIBCLANG_PATH` if the loader cannot find it.

## Verification

```bash
HNL=../host-cli/target/debug/hnl scripts/hnl-gate.sh
```
