# lib-tls-libssl

Nonblocking TLS primitives over libssl — step functions a scheduler can park
on. The libssl bindings are sdkgen-generated and emitted under
`handl-packages/generated/` (a gitignored build artifact).

Part of the `handl-lang` org split (ADR-0128). History is a `git subtree
split` of the platform monorepo's `tls-libssl/` (via `c`).

## Layout

```text
src/        the .hnl sources
specs/      committed sdkgen inputs (libssl.sdkgen.yaml)
handl-packages/generated/   build artifact — regenerated by the gate
pkg.hnl     dependencies, when any: `{ deps: { <name>: "branch:<ref>" } }`
```

## Regenerate

```bash
hnl sdkgen c /usr/include/openssl/ssl.h \
  --output handl-packages/generated/libssl \
  --config specs/libssl.sdkgen.yaml
```

(needs libclang — set `LIBCLANG_PATH` if the loader cannot find it)

## Gate

```bash
HNL=../host-cli/target/debug/hnl scripts/hnl-gate.sh
```

The gate regenerates `handl-packages/generated/` from `specs/` first, then
typechecks/lints/tests whatever `.hnl` sources exist.
